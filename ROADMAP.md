## 🎯 High-Level Milestones

- **v1.1 (Current)**: Local-first AES-GCM Vault, Xterm.js PTY, Dual-Pane SFTP Explorer, Liquid Glass UI.
- **v1.2 (Next)**: Command Palette (`Cmd+K`), Terminal Split Panes, Snippets Library, SSH Port Forwarding / Tunnels, Bastion / ProxyJump, In-App Text/Config Editor.
- **v1.3**: Production Safeguards, Multi-Exec Broadcast, SSH Agent / Hardware Keys (YubiKey), Host Health Monitoring, Session Logging.
- **v1.4+**: Zero-Knowledge Self-Hosted Sync (WebDAV/S3), Biometric Unlock (Touch ID/Windows Hello), Remote File Diff.
