## 🎯 High-Level Milestones

- **v1.0 – v1.3 (Completed)**: Local-first AES-GCM Vault, Xterm.js Native PTY, Dual-Pane SFTP Explorer, Pointer Drag-and-Drop, Command Palette (`Cmd+K`), Built-in Text/Config Editor, Permissions/Chmod/Chown Inspector, and Image Viewer.
- **v1.4 (Next)**: Curated Theme Gallery & Live Switcher, Smart Clickable Links & SFTP Editor Jump, Tab Color Tags & Renaming, Terminal Split Panes, Multi-Exec Broadcast, SSH Keep-Alive, Session Logging, Terminal Buffer Search (`Cmd+F`), SSH Port Forwarding / Tunnels, Bastion / ProxyJump, OpenSSH `~/.ssh/config` Import, SSH Key Pair Generator & `ssh-copy-id`, Snippets Library, Server Notes / Runbooks Drawer, Remote Archive Extraction, Background SFTP Transfer Queue, Host Health Monitoring.
- **v1.5+**: Quake / Dropdown Global Hotkey Terminal, Smart Output Highlighting & Triggers, ZMODEM (`rz`/`sz`), Mosh Protocol, Serial/USB & Telnet, Synchronized Dual-Pane SFTP Browsing, External Editor Watcher, Docker & Container Explorer, Hardware Security Keys (YubiKey/FIDO2), Biometric Unlock (Touch ID/Windows Hello), Self-Hosted Encrypted Sync (WebDAV/S3).
